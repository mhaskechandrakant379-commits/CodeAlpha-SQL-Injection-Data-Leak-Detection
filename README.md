\# SQL Injection Data Leak Detection



A Python Flask-based web application designed to demonstrate SQL Injection risks and help detect potential data leakage through security testing.



\## Project Overview



This project demonstrates how SQL Injection vulnerabilities can affect web applications and how security mechanisms can help protect sensitive information.



\## Features



\- User registration and login

\- Secure password hashing

\- Encrypted sensitive data storage

\- SQL Injection security testing

\- Security event logging

\- Dashboard for viewing application activity

\- Flask-based web interface



\## Technologies Used



\- Python

\- Flask

\- SQLite

\- HTML

\- CSS

\- SQL

\- Cryptography
